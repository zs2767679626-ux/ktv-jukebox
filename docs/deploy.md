# 部署指南

## 一、局域网模式（推荐）

服务器与播放端都跑在公司那台连蓝牙音箱的电脑上；员工手机连办公室 Wi-Fi，用浏览器访问点歌。

### 1. 安装（公司电脑，Windows）

1. 把整个项目文件夹拷到公司电脑（如 `C:\ktv-jukebox`）
2. 双击根目录 `setup_lan_win.bat`，按提示走完：
   - 检查/安装 Node.js 23.4+（无则提示去 nodejs.org 装 LTS）
   - 安装服务器依赖（首次自动 `npm install`）
   - 生成 `server\.env`（设备口令，默认 `ktv-2026-xj`，可改——播放端要一致）
   - 防火墙放行 3000 端口（失败也没关系，首次启动时 Windows 弹窗点"允许"）
   - 注册开机自启（服务器 + 播放端各自一条）
   - 启动服务器，打印局域网访问地址
3. 接着完成播放端安装（脚本自动衔接）：`player_config.json` 里 server 填 `ws://127.0.0.1:3000`，token 与 `.env` 一致
4. 播放前把系统默认音频输出切到蓝牙音箱

### 2. 使用

- 员工手机（办公室 Wi-Fi）：浏览器打开 `http://<电脑IP>:3000`（安装脚本会打印，也可在服务器窗口看）
- 服务器每次启动会在窗口打印访问地址与网易云登录状态

### 3. 网易云登录（会员歌播放）

1. 手机页面顶栏点「🎵 网易云」→ 弹出二维码
2. 用网易云音乐 App 扫码（扫完在手机上点「确认登录」）
3. 登录后顶栏显示账号昵称和会员类型，VIP 歌即可正常播放
4. 登录态保存在服务器本地 SQLite，重启不丢；Cookie 过期后 VIP 歌恢复跳过，重新扫码即可

> 未登录时：免费歌正常播放，VIP/付费歌搜得到（带标签）但播不了，自动跳下一首并在历史注明。
> 也可不用扫码：服务器设 `NETEASE_COOKIE` 环境变量（`MUSIC_U=xxx` 形式，见下文"云端部署"第 4 步的获取方式），扫码登录会覆盖它。

### 4. 常见问题

- **手机打不开页面**：确认手机和电脑在同一网络；检查 Windows 防火墙弹窗是否点了"允许"；公司路由器开了"AP 隔离"的话需要关闭（或电脑开热点给手机连）
- **重启后没自动起**：开始菜单"启动"文件夹里应有 `点歌台服务器` 与 `点歌台播放端` 两个快捷方式

## 二、云端部署（可选）

把服务器放公网（手机不在办公室也能点歌）。可用任意 Node 托管平台（如腾讯 CloudStudio / Render / Railway）：

1. 代码推 GitHub 或打包 zip
2. 平台导入仓库/zip，运行时 Node ≥23.4；启动命令 `cd server && npm install && npm start`（平台注入 PORT）
3. 环境变量：
   - `DEVICE_TOKEN`：设备口令（播放端连接用）
   - `NETEASE_REAL_IP`：可选，网易云 API 限流时填国内 IP
   - `NETEASE_COOKIE`：可选，初始登录态 `MUSIC_U=xxx`（也可上线后在页面扫码登录）
4. 获取 MUSIC_U：浏览器登录 music.163.com → F12 → Application → Cookies → 复制 `MUSIC_U` 整串值
5. 播放端 `player_config.json` 的 server 填 `https://<域名>`

## 三、验收清单

- [ ] 手机打开网址 → 搜索点歌 → 蓝牙音箱出声
- [ ] 多人页面：A 调音量，B 页面 1 秒内同步；A 切歌立刻生效
- [ ] 已点列表置顶/删除
- [ ] 播放端电脑关机 → 页面提示离线、点歌照常排队；开机重连自动接着播
- [ ] 歌词滚动高亮；纯音乐正常显示
- [ ] VIP 歌有标签；未登录时播不了自动跳下一首并注明；扫码登录后正常播放
- [ ] 服务器重启：队列清空、历史保留、网易云登录态保留

## 四、日常维护

- 服务器日志：服务器启动窗口（或自启后看 `player/player.log` 之外的服务器输出）
- 播放端日志：`player/player.log`
- 历史记录库：`server/data/jukebox.db`（登录 Cookie 也在这里的 settings 表）
- 网易云登录失效（VIP 歌又开始跳）：重新扫码登录即可
